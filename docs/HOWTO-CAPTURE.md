# 参数获取说明

这份文档解决一件事：**把参数换成你自己学校的。**

> 本仓库不附带任何学校的真实参数。所有示例值都是占位符。
> 参数来自**你自己账号**里那张表单的页面地址，不需要任何抓包工具。

---

## 0. 三条路，从易到难

| 档 | 做法 | 需要什么 | 难度 |
|---|---|---|---|
| **① 同校同学已配好** | 让对方把四个参数发你，自己只需扫码 | 一个已配置好的同学 | 零 |
| **② 从 App 分享链接里读**（推荐） | 学习通里打开表单 → 分享 → 复制链接 | 手机 + App | 低 |
| **③ 从浏览器地址栏读** | 电脑浏览器打开同一张表单 | 能登录网页版 | 低 |

**参数是「学校维度」的，不是「人维度」**：同一个学校的同一张日报，
`form_id` / `enc` / `fid_enc` / `state_fid` 完全一样。所以同校的人不必各查一遍。

> 但**登录状态是「人维度」的**：不要把自己的 Cookie 发给别人，也不要用别人的 Cookie。

### 关于手机抓包

装根证书、设代理、解 HTTPS 那一套，不同系统还不一样。
**上面三条路都走不通时再考虑，本文不提供该方法的步骤。**

---

## 0.5 前提条件

| 东西 | 说明 |
|---|---|
| 一个能正常打卡的账号 | 你自己的 |
| 手机上的学习通 App | 用来找入口；网页版有时找不到应用 |
| **已经填过一次的日报** | **必须**：没填过就没有历史记录，「自动同步表单」拿不到模板 |

> 今天已经打过卡也没关系——下面的路线不需要重新提交。

---

## 1. 四个参数是什么

| 配置字段 | 地址里对应 | 说明 |
|---|---|---|
| `form_id` | `formId` | 这张表单的编号 |
| `enc` | `applyenc`（**不是** `enc`） | 页面级参数，每次提交都用同一个 |
| `fid_enc` | `fidEnc` | 学校维度的参数 |
| `state_fid` | `state` | 学校租户编号 |

> 地址里的 `enc` 是**那条提交记录的标识**，每条都不一样，**不能拿去提交**。
> 详情页里真正的页面参数叫 `applyenc`。面板的「解析并保存」已经处理了这个区别。

---

## 2. 路线 ②：从 App 分享链接里读（推荐）

```text
1. 学习通 App →「已提交的记录」→ 点开那条日报
2. 右上角「…」→ 分享 → 复制链接
3. 把链接发到电脑（微信文件传输助手就行）
4. 面板「③ 运行设置」→ 粘贴到「表单链接」→ 点「解析并保存」
```

四个参数会自动填好，**不用手动抄**。

---

## 3. 路线 ③：从浏览器地址栏读

```text
1. 电脑浏览器登录网页版学习通
2. 打开同一张健康日报表单，停在填写页（不要提交）
3. 看地址栏，里面能找到 formId / applyenc / state / fidEnc
4. 整条粘贴到面板「表单链接」→ 点「解析并保存」
```

**地址栏里没有手机端参数时**：按 `F12` → 点左上角设备图标（或 `Ctrl+Shift+M`）→
顶部选一个手机型号，页面会重载成手机版，这时地址栏通常就带上了。

---

## 4. 登录状态怎么来

**优先用面板的「扫码添加用户」**：本人用学习通 App 扫一下，登录状态自动保存并加密存储。

> 不需要手动复制任何 Cookie。

只有命令行模式（无面板）才需要在配置里填 `cookie` 字段。

---

## 5. location 怎么写

格式是 `纬度,经度,地址`，例如：

```text
30.00000000,114.00000000,某某大学东门
```

拿坐标：打开地图 → 在你要填的位置右键 → 第一项就是坐标 → 复制。

> 这一项会原样提交给学校，请填真实位置。

## 6. 先验证一次

**面板**：「③ 运行设置」→ 打开「演练模式」→「⑥ 用户」→ 点「试跑」。

**命令行**：

```bash
python standalone/cli.py --config config.local.json --dry-run
```

成功的样子：

```text
dry-run 通过：Cookie 有效，已取到 checkCode
```

**演练模式不会产生任何打卡记录**，随便试。验证通过后记得把它关掉，否则永远不真提交。

## 7. 换了学校怎么办

参数按学校走。换学校就重新走一遍上面的流程——本仓库不预置任何学校的数据。

---

## 8. 常见报错对照

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 解析后提示「缺参数」 | 链接不是详情页（可能是列表页） | 从「已提交的记录」点进详情再分享 |
| `Cookie 已失效` / `请重新登录` | 登录状态过期 | 面板里重新扫码 |
| `302 跳转里没有 checkCode` | 未登录，或参数不对 | 确认浏览器里仍是登录状态 |
| `缺少 uuid / submitVersion` | 从没提交过，自动同步拿不到 | 先在学校页面手动交一次 |
| `每个用户每日只能填写1次` | 今天已经打过 | **这是成功**，插件按成功处理 |
| `HTTP 403` | 当前网络环境未通过平台的常规校验 | 见 README「登录助手」 |
| 表单已关闭 / 不存在 | 学校停了这张表 | 找学校确认，或换新表链接 |

---

## 9. 安全提醒

- Cookie 等同于登录凭证，**泄露即失守**
- `config.local.json`、`accounts.json`、`secret.key` 已在 `.gitignore`，别手滑提交
- 不要用别人的 Cookie；退出登录后 Cookie 会失效
- 服务器地址不要发到公开场合
