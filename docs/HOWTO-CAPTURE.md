# 参数获取说明

> 本工具不附带任何学校的真实参数。要让它工作，你需要【自己学校】的一整套参数。
> 这些参数来自**你自己账号**里那张表单的页面地址，不需要任何抓包工具。

---

## 0. 三条路，从易到难

| 档 | 做法 | 需要什么 |
|---|---|---|
| **① 同校同学已配好** | 让对方把四个参数发你 | 一个已配置好的同学 |
| **② 从 App 分享链接里读**（推荐） | 学习通里打开表单 → 分享 → 复制链接 | 手机 + App |
| **③ 从浏览器地址栏读** | 电脑浏览器打开同一张表单 | 能登录网页版 |

> 三条路拿到的都是同一组参数，没有区别。

---

## 1. 四个参数是什么

| 配置字段 | 地址里对应 | 说明 |
|---|---|---|
| `form_id` | `formId` | 这张表单的编号 |
| `enc` | `applyenc`（不是 `enc`） | 页面级参数，**每次提交都要用同一个** |
| `fid_enc` | `fidEnc` | 学校维度的参数 |
| `state_fid` | `state` | 学校租户编号 |

---

## 2. 路线 ②：从 App 分享链接里读（推荐）

```text
1. 学习通 App →「已提交的记录」→ 点开那条日报
2. 右上角「…」→ 分享 → 复制链接
3. 把链接发到电脑（微信文件传输助手就行）
4. 面板「③ 运行设置」→ 粘贴到「表单链接」→ 点「解析并保存」
```

四个参数会自动填好，**不用你手动抄**。

---

## 3. 路线 ③：从浏览器地址栏读

```text
1. 电脑浏览器登录网页版学习通
2. 打开同一张健康日报表单
3. 看地址栏，里面能找到 formId / applyenc / state / fidEnc
4. 同样整条粘贴到面板，点「解析并保存」
```

---

## 4. 登录状态怎么来

**优先用面板的「扫码添加用户」**：本人用学习通 App 扫一下，登录状态自动保存并加密存储。

> 不需要手动复制任何 Cookie。

---

## 5. 换了学校怎么办

参数是**按学校**的。换学校就要重新走一遍上面的流程——本仓库不预置任何学校的数据。

---

## 6. 常见情况

| 现象 | 原因 | 处理 |
|---|---|---|
| 解析后提示"缺参数" | 链接不是详情页（可能是列表页） | 从「已提交的记录」里点进详情再分享 |
| 提交返回 403 | 当前网络环境被平台判定异常 | 换网络，或在面板里重新扫码登录 |
| 提交返回"已达上限" | 今天已经提交过 | 正常，按成功处理 |
| 表单已关闭 | 学校停了这张表 | 找学校确认，或换新表 |
