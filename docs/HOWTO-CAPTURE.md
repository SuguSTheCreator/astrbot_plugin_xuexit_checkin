# 怎么换成你自己学校（抓包教程）

这份文档解决一件事：**把别人仓库里的参数，换成你自己学校的。**

> 本文站内路径以「学习通 / 超星」网页版为准，学校不同，页面长得可能略有差异，但请求名字基本一致。

---

## 0. 四条路，难度从低到高

拿参数不是只有「手机抓包」一条路。按顺序试，**多数人走到第 2 档就够了**。

| 档 | 做法 | 需要什么 | 难度 |
|---|---|---|---|
| **① 抄现成的** | 同校同学：用主账号配好的参数，自己只需扫码 | 什么也不用 | 零 |
| **② 复制链接** | 手机上拿到表单页网址，发到电脑，一条命令抠参数 | 手机浏览器 | 低 |
| **③ F12 设备模拟** | 电脑上切成手机模式打开表单 | 会用 DevTools | 中 |
| **④ 手机抓包** | 装证书、开代理、解 HTTPS | 折腾半天 | 高 |

**先别急着上第 ④ 档。**

---

### ① 同校同学：根本不用抓

参数是**学校维度**的，不是人维度：同一个学校的日报，`form_id` / `enc` / `fid_enc` / `state_fid` 完全一样。

同校的人只需要：

1. 用自己的学习通**扫一次码**（绑到自己账号）
2. 剩下交给已经配好的服务

**不要把自己的 Cookie 发给别人，也不要用别人的 Cookie。**

---

### ② 复制链接（推荐给要自己配的人）

1. 手机浏览器（不是 App）打开学习通网页版并登录
2. 进到表单填写页
3. 长按地址栏 → 复制（或分享 → 复制链接）
4. 把网址发到电脑
5. 电脑上跑：

```bash
python tools/from_url.py "粘贴那条网址"
```

输出就是四个参数：

```text
抓到的参数：
  form_id    123456
  enc        0123456789abcdef…
  fid_enc    0123456789abcdef
  state_fid  39037
```

加 `--out config.local.json` 还能顺手生成配置骨架。

> 网址里要带 `fore/apply`（或 `forms`）和 `formId` / `id`。登录页（`passport2`）不算，工具会直接告诉你缺哪几个。

---

### ③ 电脑上模拟手机

1. 电脑 Chrome 打开表单页
2. 按 F12 → 点左上角设备图标（或 Ctrl+Shift+M）
3. 顶部选一个手机型号，页面会重载成手机版
4. 这时地址栏里的网址通常就带上手机端参数了

---

### ④ 手机抓包（最后手段）

要装根证书、设代理、解 HTTPS，不同系统还不一样。**除非前三条都走不通，否则别走这条。**

---
## 0.5 你需要准备什么

| 东西 | 从哪来 |
|---|---|
| 一个能正常打卡的超星账号 | 你自己（学号 + 密码，或扫码登录） |
| 手机上的「学习通」App | 用来找入口；网页版有时找不到应用 |
| 电脑上的 Chrome / Edge | 抓包用，手机做不了 F12 |
| 已经填过一次的日报 | **必须**：没填过就没有历史记录，自动同步拿不到模板 |

> 如果今天已经打过卡，也没关系——下面的「路线 A」不需要重新提交。

---

## 路线 A（推荐，2 分钟）：从地址栏抄参数

### 第 1 步：打开表单页

1. 浏览器登录 `https://office.chaoxing.com`
2. 找到「健康日报 / 每日填报」那个表单，点进去
3. 停在**填写页面**（不要提交）

### 第 2 步：看地址栏

地址栏大概长这样（参数顺序可能不同）：

```text
https://office.chaoxing.com/front/web/apps/forms/fore/apply
    ?formId=123456
    &enc=0123456789abcdef0123456789abcdef
    &fidEnc=0123456789abcdef
    &stateFid=39037
```

抄下这 4 个值：

| 配置字段 | 地址栏参数 | 例子 |
|---|---|---|
| `form_id` | `formId` | 123456 |
| `enc` | `enc` | 01234567… |
| `fid_enc` | `fidEnc` | 0123456789abcdef |
| `state_fid` | `stateFid` | 39037 |

> 个别学校地址栏里没有 `fidEnc`，用路线 B。

### 第 3 步：拿 Cookie

1. 在那个页面按 `F12`
2. 顶部切到 **Network（网络）**
3. 按 `F5` 刷新页面
4. 左边随便点一个请求 → 右边 **Headers（标头）**
5. 找到 `Request Headers` 里的 `Cookie:`，**整行复制**

> 这一行等于你的登录凭证，**不要发给任何人，不要提交到 git**。

### 第 4 步：填进配置

```json
{
  "cookie": "（第 3 步复制的那一整行）",
  "form_id": "123456",
  "enc": "……",
  "fid_enc": "……",
  "state_fid": "……",
  "uuid": "留空也行",
  "submit_version": "留空也行",
  "form_template": {},
  "location": "纬度,经度,地址",
  "dry_run": true,
  "state_path": "state.json"
}
```

`uuid` / `submit_version` / `form_template` **可以留空**——插件开着「自动同步表单」时，会自己从你上一次提交里取。

---

## 路线 B（地址栏不全时）：Copy as cURL

### 第 1 步：抓一次提交请求

1. 打开表单页，先按 `F12` → Network → 勾上 **Preserve log（保留日志）**
2. 正常填完并提交一次
3. 列表里找到名字带 `fore/user/save` 的请求
4. 右键 → **Copy** → **Copy as cURL (bash)**

> 一天只能提交一次。如果你今天已经交过，就把这一步留到明天，或者直接用路线 A。

### 第 2 步：交给脚本解析

把复制的内容存成 `capture.txt`，然后：

```bash
python tools/from_curl.py capture.txt --out config.local.json \
    --fid-enc 你的fidEnc --location "纬度,经度,地址"
```

输出会告诉你抓到了什么：

```text
已写入：config.local.json
抓到的字段：cookie=1580 字符 | form_id=123456 | uuid=0000aaaa… | submitVersion=… | 模板字段数=23
```

---

## 第 4 步：location 怎么写

格式是 `纬度,经度,地址`，例如：

```text
30.39037787,114.54092439,某某大学东门
```

拿坐标：打开地图 → 在你要填的位置右键 → 第一项就是坐标 → 复制。

> 这一项会原样提交给学校。填太离谱的值，辅导员那边可能看得见。

---

## 第 5 步：先 dry-run 验证

```bash
python standalone/cli.py --config config.local.json --dry-run
```

或者把配置里的 `"dry_run"` 改成 `true` 再跑。

成功的样子：

```text
dry-run 通过：Cookie 有效，已取到 checkCode
```

**dry-run 不会产生任何打卡记录**，随便试。

## 常见报错对照

| 报错 | 原因 | 怎么办 |
|---|---|---|
| `Cookie 已失效` | Cookie 抄错 / 过期 | 重新走第 3 步 |
| `302 跳转里没有 checkCode` | 没登录，或参数不对 | 确认浏览器里还是登录状态 |
| `缺少 uuid / submitVersion` | 从没提交过，自动同步拿不到 | 先手动在学校页面交一次，或走路线 B |
| `提交失败：每个用户每日只能填写1次` | 今天已经打过 | **这是成功**，插件会按成功处理 |
| `HTTP 403` | 机房 IP 被拦 | 见 README「登录助手」 |

## 安全提醒

- Cookie 等于账号密码，**泄露即失守**
- `config.local.json` 已在 `.gitignore`，别手滑提交
- 不要用别人的 Cookie；退出登录后 Cookie 会失效
