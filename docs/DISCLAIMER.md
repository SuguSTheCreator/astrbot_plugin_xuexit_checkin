# 使用声明与免责

## 这是什么

一个**个人自用**的脚本：把学校每日健康日报的填写流程自动化。
它不代替任何人做判断，只把「重复点一样的按钮」这件事交给程序。

**本仓库不包含任何真实账号数据**，所有示例参数都是占位值。

1. **你已阅读并遵守所在学校的规定**。
   如果学校要求必须由本人手动提交，那么用本工具可能不符合校内要求——这一点需由使用者自行判断并承担。

2. **你遵守 XUEXITONG 的用户协议**。
   用脚本代替人工操作，可能被平台认定为异常行为。账号被限制或被封禁的风险由使用者自负。

3. **你理解它可能失效**。
   Chaoxing 改版、表单更换、Cookie 过期都会让它打不上卡。**不要把它当成唯一保障**，
   重要的事情自己确认一遍。
